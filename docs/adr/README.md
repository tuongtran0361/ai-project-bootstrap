# Architecture Decision Records

ADRs preserve decisions that materially affect architecture, governance, security, data, public contracts, or hard-to-reverse operating policy.

## Status values

- `Proposed`: under review and not yet authoritative.
- `Accepted`: current source of truth.
- `Superseded`: replaced by a newer ADR.
- `Rejected`: considered but not adopted.
